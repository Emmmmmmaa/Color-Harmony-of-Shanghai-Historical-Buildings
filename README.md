- This dataset features **360-degree panoramic street view images of all accessible [outstanding historical buildings in Shanghai](https://en.wikipedia.org/wiki/List_of_outstanding_historic_buildings_of_Shanghai)**, sourced from Baidu Street View.
- The included Excel file contains the results of color harmony measurements for these historical buildings.
For more details, please refer to the paper: [A novel approach for assessing color harmony of historical buildings via street view image](https://www.sciencedirect.com/science/article/pii/S2095263524000402?via%3Dihub).
